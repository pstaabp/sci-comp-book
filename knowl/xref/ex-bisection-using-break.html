Check Your Understanding 5.5.

Rewrite the bisection method above using a while true and use the short-circuit with the break statement to ensure there is an exit from the loop.
🔗
Solution. 
function bisection(f::Function, a::Real, b::Real)
  local c
  local n = 0
  while true
    c = 0.5*(a+b)  # find the midpoint
    # test if f(a) and f(c) have opposite signs to determine the new interval
    (a,b) = f(a)*f(c) < 0 ? (a,c) : (c,b)
    ((b-a) < 1e-6 || n > 10) && break
    n += 1
  end
  c
end
Note that there was an extra condition added. This is basically to make sure that eventually (after 10 steps), the while loop will end. If you don’t have a function with a root or the initial interval does not have a root, then this function may not end.
